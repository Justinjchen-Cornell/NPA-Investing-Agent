# NPA-Investing-Agent · 不良资产投资智能体知识库

> 一个可被 AI 智能体（Claude Code / GitHub Copilot CLI 等）直接调用的不良资产投资知识库，同时也是供从业者随时翻阅的实战手册。

**✅ 已完成**：46 章正文 + 智能体技能入口（SKILL.md）+ 术语表 + 模式库 + 速查决策表。

## 使用方式

**作为智能体技能**（Claude Code 等）：
```bash
git clone https://github.com/Justinjchen-Cornell/NPA-Investing-Agent.git ~/.claude/skills/npa-investing
```
重启会话即可——智能体会通过 SKILL.md 检索本知识库，支持按主题/章节定位。

**作为人工手册**：直接浏览 `chapters/` 目录，按篇目查阅；`cheatsheet.md` 是放在手边的单页决策工具。

## 数据来源

本库为学习研究用途的**提炼总结**（**不包含原书文本**），基于以下著作的研读：

1. 石佳华《一本书读懂不良资产》（中国法制出版社）
2. 马丁·J.惠特曼、费尔南多·迪茨《不良资产投资：理论与方法》（Distress Investing 中译本）
3. 蔡春雷主编《掘金之旅：金融不良资产处置十八般武艺》（法律出版社）
4. 蔡春雷主编、邵雷雷副主编《掘金之旅：投资金融不良资产疑难案例精析》
5. 中国东方资产管理股份有限公司《特殊机会投资之道——金融资产管理公司法律实务精要》
6. 戚桂林、郭玉春、曾惠东主编《不良资产经营管理》

其中 2、3（案例集）、6 三本为扫描版书籍，经 OCR 识别后提炼（此说明用于透明记录处理过程）。
