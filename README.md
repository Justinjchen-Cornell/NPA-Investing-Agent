# NPA-Investing-Agent · 不良资产投资智能体知识库

> 一个可被 AI 智能体（Claude Code / GitHub Copilot CLI 等）直接调用的不良资产投资知识库，同时也是供从业者日常翻阅的实战手册。

**🚧 生成中**：已发布「行业认知篇」（第1–6章），其余篇章持续更新中。

## 规划内容
- **行业认知篇**：不良资产的本质与分类、成因、市场格局、参与主体、AMC、行业变局 ✅
- **收购与尽调篇**：尽调八法、收购流程、评估与拍卖
- **投资理论与估值篇**：惠特曼《Distress Investing》核心框架（五大真相、自愿交换、重组流程、案例研究）
- **投后管理与处置篇**：债务重组、债转股、证券化、18般处置武艺、破产清算与追责
- **法律实务篇**：债权投资、担保措施、类担保、争议解决
- **案例精析篇**：程序篇与实体篇实战判例
- **政策与监管篇**：监管办法与核心司法解释速览
- **支撑层**：SKILL.md（智能体技能入口）、术语表、方法模式库、速查决策表

## 数据来源
本库为学习研究用途的**提炼总结**（不包含原书文本），基于以下著作的研读：
石佳华《一本书读懂不良资产》；惠特曼/迪茨《不良资产投资：理论与方法》（Distress Investing 中译本）；蔡春雷主编《掘金之旅：金融不良资产处置十八般武艺》《掘金之旅：投资金融不良资产疑难案例精析》；中国东方资产《特殊机会投资之道》；戚桂林等主编《不良资产经营管理》。

## 使用方式（完成后）
- **作为技能**：将本仓库克隆到 `~/.claude/skills/`（或 Copilot skills 目录）即可被智能体自动检索调用；
- **作为手册**：直接浏览 `chapters/` 目录，按篇目查阅。
